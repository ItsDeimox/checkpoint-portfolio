# Continuous card hover correction

Baseline: `910bb08f6e69086c9b86849e05925d7a4882dc40`, retaining the subsequent portal/performance work already present in that commit.

The rejected Prism Trails shader built its diagonal fragments and incomplete rings around the *current* pointer. Its geometry-like pattern translated with the pointer instead of recording the travelled path. That is removed from the card runtime.

Cards now record at most 16 samples of bottom-up physical mesh UVs. The newest tip follows input exactly; old samples stay fixed on the card, join into continuous strokes, broaden slightly and fade over 0.72 seconds. Sampling coalesces at 30 Hz while retaining the newest tip every frame. A stationary pointer does not renew the wake, and leaving/reentering never connects unrelated strokes. The nearest recorded segment is refined into a tangent-bounded curve, avoiding angular joints without adding samples or render passes. The visual is a restrained soft wake with rounded highlights, not fragments or moving diagonal lanes. Existing cube-wave energy adds subtle local luminance only; Play Now is unchanged.

The original graph, atlas, five colors and scene lifecycle are retained. There are no additional textures, canvases, render targets, render passes or animation callbacks. History arrays allocate once; the shader has a fixed 16-sample bound, four existing atlas reads, and computes exponentials once per pixel, outside the history loop. Portal travel clears the wake; reduced motion disables it. No changes to main, capture, portal geometry, quality, GPU scheduling, camera, lighting or vehicle code.

Validation includes six new CPU regressions that failed on Prism Trails before the correction. They test retained positions, UV orientation, sparse-movement continuity, leave/reentry, stationary decay, bounded storage, resource stability and hidden/reduced-motion behavior. The existing full test suite is retained, replacing only assertions requiring the rejected shader. `card-flow-browser.cjs` renders the actual patched card material: it checks head, midpoint, tail, untouched regions, fixed deposition and complete decay for all five cards; it also saves a turning-gesture frame sequence. Native input and portal behavior are checked separately by the existing stability browser suite. Software-GPU tests are not an RTX 2060 performance benchmark.
