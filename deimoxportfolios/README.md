# Deimox Portfolios

Production source for the Deimox portfolio showcase.

- WebGL 2 + GLSL rendering
- 3D draggable portfolio carousel
- Vertex-energy hover propagation
- Velocity-driven mesh deformation
- HDR-style lighting and bloom
- Responsive pointer, wheel, touch and keyboard navigation

Deployment target: https://deimoxportfolios.vercel.app/
