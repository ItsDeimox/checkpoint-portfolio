# Dark metal lighting preset

Scope: the existing showroom's lighting, car materials and Light & lens values.
Camera, screen geometry, navigation, hover, beam geometry and render passes are unchanged.

## Requested controls

Exposure 1.15; bloom 0.65; depth of field 1.50; motion blur 1.00;
lens response 1.00; sharpness 0.35. Contrast is **1.74**, exactly
1.5 times the screenshot's 1.16, not a 150% addition.
The contrast slider now permits 0.90 to 2.00.

New visits and Restore visual defaults use this preset. Old saved contrast
at the previous 1.16 ceiling maps to 1.74. Other saved choices remain intact.
The next explicit settings save records visualPreset=dark-metal-v1, so later
choices, including a manually restored 1.16, survive reloads. The migration
never repeatedly multiplies a value. Quality and paused state are preserved.

## Car and light treatment

Body and Hood keep the original red color, meshes, maps and clearcoat layer.
Metalness changes from 0.42 to 0.78, base roughness from 0.24 to 0.16,
environment response from 1.35 to 1.85, and clearcoat roughness from 0.10 to
0.065. Chrome and glass highlights sharpen slightly with nonzero roughness.
Rims, tires, interior, lamps, window opacity and transmission remain unchanged.

The global hemisphere fill is reduced from 0.23 to 0.105 and the broad key
from 2.7 to 1.7. The existing five area lights are retuned into narrower
white and red highlight strips. The inherited white reflection studio is
dimmed before its four authored strips are added, using the same bounded
one-time PMREM capture. No new real-time lights, shadow maps or passes are added.

## Verification

The new preset, migration, lighting and material tests were checked failing
before implementation. The complete build then passed 154 tests, including
real GLB material and unchanged-geometry checks. Changes to the sliders still
persist on change rather than on every input event.

The minified renderer is generated by npm run build or npm run dev from the
updated scene modules. The generated file is not hand-edited in this change.
