Antes / Depois

Do “por que isso tá dando 500?”
ao fluxo funcionando.

Exemplo simplificado de um problema comum: endpoint mistura regra de negócio, banco e tratamento de erro. Funciona até não funcionar.

Antesapi/users.ts
export async function POST(req) {
  const body = await req.json()
  const user = await db.user.create({
    data: body
  })
  sendWelcomeEmail(user.email)
  return Response.json(user)
}
Sem validação, sem rollback, sem tratamento de erro, side effect solto.
Depoisapi/users.ts
export async function POST(req: Request) {
  try {
    const payload = schema.parse(
      await req.json()
    )
    const user = await createUser(payload)
    await queueWelcomeEmail(user.id)
    return Response.json(user, { status: 201 })
  } catch (error) {
    return handleApiError(error)
  }
}
Validação, fluxo previsível, side effects controlados e erro tratável.
